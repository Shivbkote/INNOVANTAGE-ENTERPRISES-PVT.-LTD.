# Innovantage Enterprises website — starter project

This project contains the shared website foundation and a first homepage build in plain HTML, CSS and JavaScript.

## Included
- `index.html` — homepage with responsive navigation, consulting content, process, H.E.L.P. introduction, resource categories and discovery-call CTA.
- `css/styles.css` — global design tokens, responsive layouts, navigation, homepage styles, animations and reduced-motion support.
- `js/main.js` — accessible mobile navigation, dropdown behavior, reveal animations and dynamic copyright year.
- `pages/` — initial inner-page scaffolds for About, Services, H.E.L.P., Resources, FAQs, Contact, booking and policy pages.
- `assets/innovantage-logo.png` — original logo supplied in the conversation.

## Run locally
Open `index.html` directly for a quick preview, or use a local static server (recommended for testing relative links).

## Before publishing — items to confirm
1. Confirm the final brand colors and whether the gold value should be sampled exactly from the source logo.
2. Provide verified public contact details and the actual booking/calendar URL.
3. Add approved company/consultant biographies, photos, testimonials and case studies if available.
4. Confirm whether H.E.L.P. is only a planned platform or has any live functionality. It is labeled as planned in this starter.
5. Approve privacy, terms, cancellation and refund policy text. Current policy pages are explicitly placeholders.
6. Review all page copy against the source document before launch. Service detail pages and some individual service content still need a fuller content pass.
7. Set the production domain and update absolute canonical URLs, Open Graph URLs and sitemap when the domain is known.
8. Add a real form backend or connected form service before using contact or booking forms. The current starter does not send submissions.
9. Confirm the Organization schema and add a verified public address/telephone only if the business wants to publish them.

## SEO notes
Pages use unique titles/descriptions, semantic headings, language and viewport metadata, a favicon, and an initial Organization JSON-LD block. Add `sitemap.xml`, `robots.txt`, canonical URLs and social metadata once the live domain is known. Search ranking is not guaranteed.
